# Cmd Send v0.1.14

- 改善 Windows MobaXterm 目标绑定：可拖到会话显示区、只读输出区或同页留白，由所在页面识别具体终端，不必精确对准底部输入位置。
- 支持显示区与输入区为同页兄弟控件、系统命中跳过只读显示控件的情况；按可见页面定位，排除隐藏及完全裁切的终端。
- 分屏时绑定拖放所在的具体页面；共享区域存在多个候选时提示重新选择，不按当前焦点或枚举顺序猜选。
- 保持固定会话后台发送、连接 IP/端口展示和进程身份校验；切换页签不转投当前会话。普通输入框和其他终端继续使用原有策略。
- 保留 v0.1.13 的字符间隔设置、命令间隔及原有文件和发送功能。

验证：页面绑定回归；真实 MobaXterm 的上/中/下区域及独立只读输出兄弟控件绑定、双会话隔离、关闭目标后停止与 SSH 地址归属；双平台测试和构建；Windows 安装升级、重启及设置恢复。只读兄弟控件为受控测试夹具，不代表已经连接实际串口设备验证。

可在软件内点击版本号升级，或下载本版本的 Windows Setup.exe 安装。
