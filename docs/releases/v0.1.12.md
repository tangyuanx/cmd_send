# Cmd Send v0.1.12

- MobaXterm 目标栏优先显示绑定会话的连接 IP 和端口，例如 `192.168.1.10:22`。
- 地址来自所选终端及其 SSH/Telnet 客户端的实际 TCP 连接，不读取其他会话，也不跟随当前活动页签变化。
- 保留会话备注、PID 和输入区标识，连接同一 IP 的多个会话仍可区分；备注不会覆盖 IP。
- 支持 IPv4 和 IPv6。无法确认唯一连接地址、本地终端或存在多个连接端点时，保留原会话名称和标识。

验证：会话进程归属、PID 重用保护、TCP 地址和端口解析测试；真实 MobaXterm 双 SSH 会话 IP 显示和后台定向发送；Electron 界面、双平台构建、Windows 安装升级与重启回归。

可在软件内点击版本号检查更新，或下载本版本 Windows Setup.exe 安装。
