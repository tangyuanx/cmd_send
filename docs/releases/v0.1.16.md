新增多目标独立定时发送。

- 右侧新增「定时发送」，支持按间隔循环和在指定本机时间发送一次。
- 每个任务单独绑定目标，保存自己的指令、回车和发送间隔；可分别启动、暂停、编辑、删除。
- 实时显示任务状态、成功发送轮数、上次 / 下次时间和失败原因。
- 不同后台目标可同时发送；同一输入区或需要系统焦点的目标按完整指令排队，手动发送也参与保护，避免串字。
- 一轮未结束不重叠启动，睡眠错过的轮次不集中补发；一个目标失败不影响其他任务。
- 任务配置自动保存。退出 / 升级会停止任务，重启后需要重新绑定并启动，防止误投到复用的窗口句柄。

Windows 可通过应用顶部版本号检查更新、下载并安装重启。macOS 请下载新版压缩包。
