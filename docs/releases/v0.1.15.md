# Cmd Send v0.1.15

- 目标绑定改为直接拖选：按住「选择目标」并移动即可开始拾取，取消原来固定 400 毫秒的长按等待。
- 轻微手抖不会触发拾取；单击仍打开使用说明或已绑定目标的备注编辑，键盘激活继续可用。
- 使用指针捕获跟踪移出按钮的拖动；拾取开始后仍由原生系统监测鼠标释放，支持拖到应用窗口之外。
- 拖动结束不会误弹出说明；Esc 和指针取消会清理拖选状态，取消时保留原绑定。
- 保留 v0.1.14 的 MobaXterm 页面绑定、固定会话后台发送和字符间隔等已有功能，更新界面和使用帮助中的拖选提示。

验证：拖选状态回归，以及 Windows/macOS 实际 Electron 的快速拖动、同步触发、单击、小幅抖动、Esc 取消、移出视口和后续点击；保留真实 MobaXterm 双会话、发送与搜索、构建和 Windows 安装升级重启验证。
