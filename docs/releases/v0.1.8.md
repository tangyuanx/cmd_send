# Cmd Send v0.1.8

- 按确认的界面方案调整字体：中文优先使用黑体（Windows SimHei），英文与数字优先使用 Times New Roman，覆盖命令编辑区、按钮、设置和其他弹窗。
- 放大文字：界面正文 15px，命令正文 16px、行高 32px，辅助信息 13px；统一文字层级，优化按钮、侧栏和设置项间距。
- 保留原有黑白灰色调，增强文字与分隔线对比度，右侧操作栏使用白色表面；不增加命令行序号或命令外围黑框。
- 编辑文本层与高亮层共用相同字体、字号和行高，保持光标、选区和搜索结果定位一致。

验证：现有单元测试、真实 Electron 搜索和重复发送回归；发布流程执行双平台构建、真实 MobaXterm 兼容性、Windows 安装升级与重启验证。

字体使用系统现有字体；缺少指定字体时回退到对应平台的黑体或衬线字体。
