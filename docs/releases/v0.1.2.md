修复 Windows 选择终端、自绘输入区时提示“此区域未提供可识别的文本输入控件”的问题。

- 不再要求所有输入区必须提供 UI Automation 文本接口。无法通过该接口识别时，使用所选窗口/子控件及窗口内位置恢复输入焦点。
- 保留标准文本框后台输入，并补充 WinForms 文本框识别；只读控件、按钮等非输入区域仍会拒绝绑定。
- 发送前检查目标是否有效、所选位置是否被遮挡；发送中焦点改变或目标关闭会停止投递。
- 修复逐字符和回车发送没有返回异步 Promise 的问题，队列正确等待投递，传播错误并响应停止，避免提前显示完成。
- 增加 Windows 真实控件回归测试：无文本接口的自绘输入区、中文与 emoji、回车、焦点改变停止、标准文本框投递和目标关闭。

### 下载与运行

Windows x64 下载 `cmd-send-0.1.2-Windows-x64.zip`，完整解压后运行 `cmd-send.exe`，保留同目录全部文件。升级后重新绑定目标。Mac Apple Silicon 下载 `cmd-send-0.1.2-macOS-arm64.zip`。

长按「选择目标」，移到实际文本框或终端输入区松开。自绘输入区发送时会短暂激活并点击所选位置；调整终端页签、拆分区域或输入区布局后请重新绑定。标准文本框继续使用后台输入。

双平台自动测试和构建通过后发布。本次 Windows 回归使用受控测试窗口；MobaXterm、SecureCRT、PuTTY 等第三方终端仍需各自实机验证。目标以管理员权限运行时，本工具也需要同等权限。

包含 macOS、Windows、源码 ZIP 和 SHA-256 校验文件。
