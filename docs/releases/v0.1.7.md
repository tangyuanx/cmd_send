# Cmd Send v0.1.7

- 普通「发送」始终只发送一轮：当前命令一次，选区内有效命令按顺序各一次。
- 设置中的「重复发送」改为「重复发送模式」，只控制右侧「重复发送」按钮，保留「指定次数 / 持续循环」，删除容易混淆的「发送一次」。
- 重复发送按钮遵循设置的轮数；每轮发送完整的当前命令或选区，指定轮数完成后自动停止。
- 按钮下方同步显示发送间隔和停止条件；指定轮数重复时也正确显示运行、暂停状态。
- 重复发送结束后保留原光标和选区，方便再次发送同一组命令。旧版「发送一次」设置自动兼容为重复按钮原有的持续循环行为，保留原间隔、轮数等配置。

验证：命令解析、发送队列、文件保存、更新及目标兼容性测试；新增真实 Electron 界面回归，覆盖普通发送、指定轮数、持续循环、停止、提示和旧设置。
