本版本仅发布 Windows x64，新增定时任务拖动排序与分组统一开启。

- 定时任务左侧六点手柄支持拖动重新排序，也可用 Alt+上/下在同组内移动；支持拖入其他组，顺序与归属自动保存。
- 支持新建、重命名和删除分组；删除组会将任务移回「未分组」，保留任务内容与当前状态。
- 组内可统一开启或暂停。统一开启先检查全部待启动任务的目标和时间；已有运行任务继续原计时，不重复启动。
- 重启后保留分组、任务顺序和配置；仍需重新绑定目标并手动开启，不自动补发。
- 当前暂停 macOS 端开发与发布；本次附件不包含 macOS 安装包。

Windows 用户下载 `cmd-send-0.1.24-Windows-x64-Setup.exe`，或在现有安装版中点击版本号检查更新。安装或升级后请重新绑定目标。

任务配置兼容读取旧版，新保存的分组配置采用 version 2 格式；旧版软件不能读取新格式，回退旧版前需恢复旧配置。
