统一 Mac 和 Windows 窗口外观，移除系统标题栏与外框。

- 顶部使用应用自己的标题栏，去掉 Mac 红黄绿按钮及 Windows 系统菜单栏。
- 右上角提供统一的最小化、最大化/还原和关闭按钮，跟随浅色/深色主题。
- 顶部空白区域支持拖动窗口；保留窗口缩放和快捷键。
- 自定义关闭按钮继续执行发送停止与未保存修改检查，支持取消退出、保存或放弃修改。
- 构建包名称及应用版本统一读取项目版本号；新版本经双平台自动测试和构建后发布。

### 下载与运行

Mac Apple Silicon 下载 `cmd-send-0.1.1-macOS-arm64.zip`，解压后打开 `Cmd Send.app`。Windows x64 下载 `cmd-send-0.1.1-Windows-x64.zip`，完整解压后打开 `cmd-send.exe`，保留同目录的全部文件。

Mac 首次发送需在「系统设置 → 隐私与安全性 → 辅助功能」允许应用。Mac 包采用本地 ad-hoc 签名、未公证；Windows 包未代码签名。具体软件的输入兼容性仍需实机验证。

本版本包含源码包、示例 TXT 和 SHA-256 校验文件。
