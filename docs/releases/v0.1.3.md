# v0.1.3

Windows 改为单个 EXE 安装包，并加入软件内手动升级。

- 下载 `cmd-send-0.1.3-Windows-x64-Setup.exe`，按向导选择安装目录。首次从旧 ZIP 版迁移时，请先退出旧版，再安装并使用新快捷方式启动。
- 点击顶部版本号，手动从 GitHub 检查更新；有新版本时，点击「下载更新」，下载进度可见，安装包通过 SHA-512 校验后才能「安装并重启」。
- 升级前停止发送，并提示保存或放弃未保存的 TXT 修改；也可取消升级。安装覆盖原目录，并自动重启。
- 重启后重新打开上次的 TXT 文件和活动文件，保留发送设置与主题；不会自动恢复发送或绑定旧目标。
- 启动时不自动检查，不自动下载；普通退出不会安装已下载的更新。网络或校验失败可以重试。
- 保留 v0.1.2 的 Windows 终端/自绘输入区拾取修复。
- macOS 保留 ZIP 分发，支持软件内手动检查版本并打开 GitHub 下载页面，暂不原地升级。

Windows 为未代码签名的每用户安装包；macOS 为 ad-hoc 签名，未公证。`latest.yml` 和 `.blockmap` 用于软件升级，普通用户只需下载 Setup.exe。

发布流程验证双平台测试和构建，以及 Windows 真实安装、损坏校验拒绝、取消升级、保存后原地安装、自动重启和配置恢复。
