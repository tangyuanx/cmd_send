# v0.1.5

改善查找结果不明显、点击「下一个」后难以定位的问题。

- 所有匹配项持续高亮，当前项增加绿色边框与整行提示；焦点留在搜索输入框或导航按钮时也能看清。
- 「上一处 / 下一处」、Enter / Shift+Enter 立即定位当前项，并同时处理纵向与横向滚动；长命令右侧的结果也会进入可见区域。
- 搜索栏不再覆盖正文，顶部的匹配项也能完整显示。浅色、深色主题分别提供匹配颜色。
- 无结果时显示「无匹配」并禁用导航；清空、关闭搜索或开始发送时清理高亮，编辑或切换文件后重新计算结果。
- 按原始文本位置进行字面搜索，修复某些 Unicode 字符大小写转换导致后续位置偏移的问题；标点、中文、emoji 和 HTML 字样保持原始内容。
- 新增 Windows/macOS 实际 Electron 渲染验证，覆盖高亮、焦点、循环导航、双向滚动、主题、小窗口、编辑、保存与发送内容。

点击顶部版本号手动检查更新，下载后选择「安装并重启」。
