# Cmd Send v0.1.9

- 固定 MobaXterm 会话：切到其他页签、隐藏或最小化窗口后，仍向原绑定终端发送；原会话关闭后停止，不转投当前会话。
- 目标栏增加会话信息和唯一输入区标识。点击已绑定目标可填写备注，例如「会话1 · UART」；备注只影响显示，不改变绑定。
- 其他提供系统页签接口的 Windows 输入区记录原页签身份，发送前恢复原页签，并在发送中检查会话变化。关闭后新建同名页签不能继承旧绑定；无法可靠区分会话的共享终端会明确提示。
- 修复场景目录解析、高亮和跳转规则不一致的问题，支持独占一行的 `[标题]`、`［标题］`、`【标题】`，以及右括号后的 `#`、`//`、`;` 注释。
- 目录随编辑和文件切换实时刷新；重名标题分别定位，空场景不会跳入下一场景，没有标题时显示格式提示。
- 支持 CR 换行的 UTF-8 TXT 文件，编辑时规范化换行，保存时保留原来的 LF、CRLF 或 CR 格式。

验证：真实 MobaXterm 26.5 同窗口双会话测试，确认隐藏的绑定会话收到中文、emoji 和回车，当前会话及前台应用不收到文字，关闭原会话后停止；真实 Windows 共享输入控件页签测试；双平台目录、搜索、重复发送回归和构建；Windows 安装、原地升级及重启验证。

Windows 用户可在软件内点击版本号检查更新，下载后安装并重启，也可下载本版本的 Setup.exe 直接安装。macOS 用户下载对应 ZIP。升级后需要重新绑定目标会话。
